# 四、引入 Field Access Layer（核心设计）

## ✔ 定义统一字段模型

```kotlin id="v9q1lz"
interface FieldAccessor<T> {
    fun cost(obj: T): Int
    fun race(obj: T): String
}
```

---

## ✔ 两个实现

### 1. Card 版本

```kotlin id="h8wq1p"
object CardAccessor : FieldAccessor<Card> {
    override fun cost(obj: Card) = obj.cost
    override fun race(obj: Card) = obj.cardRace
}
```

---

### 2. ComboCard 版本

```kotlin id="k2p9xd"
object ComboCardAccessor : FieldAccessor<ComboCard> {
    override fun cost(obj: ComboCard) = obj.card.cost
    override fun race(obj: ComboCard) = obj.card.cardRace
}
```

---

# 五、Transform 只依赖“字段接口”，不依赖类型

## ✔ cost 规则变成：

```kotlin id="p0xv1m"
fun <T> costLessThan(value: Int, accessor: FieldAccessor<T>) =
    { obj: T -> accessor.cost(obj) < value }
```
